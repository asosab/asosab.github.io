Buddy

Plataforma que amplía las posibilidades de los sitios web estáticos, incorporando servicios que normalmente requieren un backend: inicio de sesión de usuarios, acceso y gestión de datos, contenido dinámico, juegos interactivos y experiencias personalizadas, manteniendo la simplicidad y las ventajas de publicar un sitio estático.

Con Buddy exploro una idea que atraviesa varios de mis proyectos: aprovechar tecnologías web sencillas para construir experiencias más completas, interactivas y útiles, sin necesidad de convertir cada proyecto en una aplicación tradicional.
